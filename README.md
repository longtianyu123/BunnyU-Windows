# 兔U电脑版

支持屏幕阅读器和全键盘操作的 Windows 音频客户端，提供验证码登录、推荐与分类、搜索播放、批量下载和自动更新。

当前版本：0.11.7。

运行 `artifacts/winforms-x64-v0.11.7/BunnyU.exe`。保留整个目录，需要 .NET 10 Windows Desktop Runtime x64，播放库已包含。

界面已从 WPF 迁移至 WinForms。主列表、下载内容及分类导航均为普通原生 ListBox，不包含表头或可展开节点；状态栏是 msctls_statusbar32。

同一 Windows 用户会话仅运行一个兔U实例。再次启动会激活现有窗口，最小化时恢复；已打开登录、设置或更新对话框时优先显示该对话框。此限制从 0.11.7 开始生效，旧版本进程需先退出。

- 未搜索时显示“推荐、分类”。推荐 → 栏目 → 作品 → 章节；分类 → 分类名 → 作品 → 章节。
- Enter：进入选中目录，在章节上播放。搜索框输入关键词后回车搜索；清空搜索框后回车回到首页。搜索结果直接显示在资源列表中。
- Backspace：返回上一层并恢复选中的条目；再次进入作品保留章节选中位置。
- 启动不请求内容。分类作品和搜索结果浏览到最后 5 项时自动追加下一页，保留选中项和滚动位置。加载完毕、空页或重复页后停止；失败不会连续重试，可用 Ctrl+PageDown 或 F5 重试。首页 F5 只刷新本地入口。
- 进入专辑时连续请求全部章节分页，加载完成后一次显示完整章节列表；浏览到末尾不再请求。F5 重新加载全部章节，失败时保留原列表；加载途中退格返回会取消请求。
- Tab / Shift+Tab：切换控件；上下键选择条目。
- Ctrl+↑ / Ctrl+↓：按首选项设置的百分比调整音量，默认 5%；左右键快退/快进 5 秒（搜索框除外）。
- 资源内空格：暂停/继续；Ctrl+空格同样可用。主界面不再有操作按钮。
- F5：刷新当前层级，尽量恢复原选中项。Ctrl+PageDown：显式加载下一页。
- F6：聚焦资源；F8：打开并聚焦状态详情（原生列表）。
- Ctrl+F：搜索；Alt / F10：经典系统菜单。
- 章节列表右键、菜单键或 Shift+F10：打开“下载 / 批量下载”。批量窗口会加载整部作品的章节；空格勾选，也可全选或取消全选，点击“开始下载”。
- 首次开始下载时选择保存文件夹，之后自动使用已保存的位置。可在“设置 → 首选项”中浏览并保存新位置。配置保存在 BunnyU.exe 同目录的 settings.json；每个专辑单独建立子文件夹，目录和文件名不添加 ID。取消首次选择不创建任务。目录失效时重新选择；配置无法写入时提示原因，不会开始任务。修改位置只影响新任务。
- 首选项窗口标题为“设置”，左侧固定分类列表只有“常规、播放”：上下键切换后 Tab 到该页设置，Shift+Tab 从首项回到分类。“常规”可设置下载完成提示音、下载保存位置，以及同时下载任务数（组合框 1–5 个，默认 1）；“播放”的组合框可选择每次音量调整百分比（1%–100%）。保存后生效，取消不应用更改。降低并行上限不打断已开始的任务，后续按新上限启动。提示音默认关闭，开启后每批全部成功下载时响一次，失败或取消不播放完成提示音。
- 点击“开始下载”后，任务加入后台队列，选择窗口自动关闭并返回原章节及选中位置。不再显示独立下载进度窗口；可继续搜索、浏览和播放，或者追加下一批下载。
- Ctrl+J 或“账号 → 下载管理”：左侧固定分类列表仅有“正在下载、下载失败、下载完成”，不含展开/折叠结构。排队任务在正在下载中，取消或中断的任务在下载失败中。上下键选分类，Tab 到对应名称列表，Shift+Tab 返回分类。列表回车查看详情、打开保存位置或取消本批任务；F5 刷新，Escape 关闭。
- 下载进度自动更新，不需要按 F5。进度变化只更新后台数据和单独绘制的进度区，不重建列表、不改选中项、不滚动，也不主动发送文本值变化播报。F8 聚焦所选任务的进度，读屏可主动查询最新百分比和大小；Ctrl+C 复制当前进度。Tab 在分类、内容、进度间切换。
- 关闭选择窗口（未点开始时）不会创建任务，关闭管理窗口不取消后台下载。退出程序会先取消未完成任务并清理临时文件。下载记录从 0.9.0 开始保存在本机，旧版本无记录的文件不会自动导入；重启不自动继续未完成任务。已存在的文件跳过。试听及未获得完整权限的章节不可下载，仅有 HLS 地址的章节暂不支持下载。
- 账号菜单提供验证码登录。只在用户点击获取验证码时发送短信；发送成功后按钮及无障碍名称显示 60 秒倒计时，期间不可重复发送，结束后恢复。
- 软件启动及每 6 小时自动检查更新，也可在“帮助 → 检查更新”手动检查。发现新版后进入强制更新窗口，显示下载进度条；完成签名与 SHA-256 校验后自动安装并重新打开。关闭强制更新窗口会退出程序。网络不可用时不会仅因检查失败强行关闭；已发现新版但更新失败时提供重试或退出。升级前停止未完成下载，账号、配置和下载历史保留。
- 更新优先通过系统网络设置直连 GitHub，失败后尝试 GitHub 下载代理站。清单使用内置公钥验证 ECDSA 签名，安装包校验清单中的 SHA-256；代理站无法替换为未签名的更新。

## 安装与更新发布

在 GitHub 仓库 `longtianyu123/BunnyU-Windows` 的 Releases 下载 `BunnyU-Setup-版本号.exe`。安装到当前用户目录，不内置 .NET 运行时，缺少时安装程序会询问是否在线下载并静默安装；无需另装 VLC。安装程序不会覆盖 `settings.json`。

使用 `.\build-installer.ps1` 生成安装包及 `artifacts/update.json`。正式发布需通过 `-SigningKeyPath` 提供发布私钥签名清单（私钥不在仓库中）。发布新版本时修改项目 Version，编译并上传同一个 Release 的安装包与已签名 update.json；保持版本、下载地址和 SHA-256 与实际文件一致。无签名清单不能用于官方自动更新。安装包和清单不得包含个人配置、登录凭据或下载记录。

窗口底部原生状态栏显示操作状态、音量、播放进度和账号；状态详情提供同样信息，供需要逐项定位的读屏使用。进度刷新不主动抢焦点或持续播报。

账户凭据沿用旧版本的 Windows DPAPI 加密文件，验证码不落盘。退出账号清理凭据和播放状态，章节需要重新显式进入加载。

## 构建

```powershell
.\build-winforms.ps1 -Publish
.\build-winforms.ps1 -Publish -LiveTests
```

Windows x64，.NET 10，LibVLCSharp 3.10.2 / LibVLC 3.0.24。旧 WPF 源码保留作为历史版本，不是当前启动入口。

权限与之前一致：需要购买或会员而无法确认完整权限的章节只播放服务提供的试听时长；不绕过付费权限。实际验证码登录仍需用户自己的手机号完成。

播放选项可设置默认音质：默认低到高，最高音质高到低。单章与批量下载提供音质组合框，默认最高，缺少地址时仅向下回退。保存播放设置后从下一次播放生效，下载仍保留权限限制。

更新安装包支持最多 16 段并行下载；服务器不支持分段时自动退回单线程，合并后验证签名清单中的 SHA-256。

精简安装包检测缺少 .NET 10 桌面运行时后会询问是否下载；同意后从微软下载并校验 SHA-256，静默安装成功后继续安装并自动启动兔U。运行时安装可能需要 Windows 管理员授权；取消或失败会保留提示供重试。运行时不打入软件安装包。

运行时在线下载采用 16 路分段下载，失败时回退兼容下载；下载助手使用 Windows 自带的 .NET Framework 4.x，不依赖待安装的 .NET 10。校验后使用 /install /quiet /norestart 静默安装，完成后启动兔U。运行时检测兼容 32/64 位注册表视图。
